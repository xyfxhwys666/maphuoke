# MapSearch 按需求消费规则

## 适用范围

本规则适用于 TaGeAI 通过 `/connector/v1/search` 消费 MapSearch 已完成采集结果的场景。

## 消费顺序

1. 从用户请求解析城市、行业或关键词、目标数量。
2. 仅检查已完成的历史采集任务。
3. 任务级关键词必须与当前请求的行业集合匹配。
4. 单条线索有 `source_metadata.matched_keywords` 时，该集合也必须与当前请求的行业集合匹配；同城但行业错配的线索不得返回。
5. 单条线索必须属于请求城市，并且高德详情采集完成、企业名称、联系方式、来源链接齐全。
6. 成功领取后写入全局消费台账，其他账号不重复领取同一条线索。
7. 没有可领取的匹配结果时，才创建新的采集任务。

## 历史兼容

历史线索可能没有 `matched_keywords`。这类记录保留任务级行业匹配作为兼容兜底；新采集流程已写入该字段，必须执行单条行业校验。

## 非目标行为

- 不向 ERP 投递。
- 不伪造企业、联系方式或采集状态。
- 不以“公开网页核验”替代高德详情采集完成。
